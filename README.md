## 🧠 About NithinIQ

![NithinIQ Logo](https://github.com/bnithin215/NithinIQ/blob/main/public/logo.png?raw=true)

**NithinIQ** is a smart document intelligence platform that lets users upload documents, extract content, and query them using an AI model powered by OpenAI’s GPT-4o-mini.  
It uses **Angular 17**, **Firebase Firestore**, and **OpenAI APIs** to build an interactive, AI-driven user experience.

**Live Website:** [https://iqnithin.web.app/](https://iqnithin.web.app/)  
**Repository:** [GitHub – NithinIQ](https://github.com/bnithin215/NithinIQ)
